## OTA

**OTA** (Over-The-Air) - совокупность обновлений для разнообразных электронных блоков автомобиля (может включать в себя и обновление мультимедиа). Автомобиль периодически проверяет актуальность установленной OTA на серверах `BYD`. Это основной путь получения обновлений ПО автомобиля для жителей Китая. Начиная с прошивки `2505` возможность получения OTA получили и жители всех остальных стран.

Запросить OTA можно и вручную - в меню `Settings > DiLink > Version > Vehicle version`. Начиная с версии прошивки `2510` визуально показывает прогресс запроса обновления, если прошивка ниже `2510` - то необходимо запросить обновление, ничего не нажимать на планшете 2-3 минуты, затем снова нажать кнопку запроса обновления. В итоге будет отображена текущая версия ОТА, либо появится окошко с предложением установить более новую версию. 

В сети описаны разнообразные методы *форсирования* получения ОТА, однако лично мне ни один из них не помог:
- возврат к прошивке `2505` и инициация запроса ОТА
- перед запросом OTA отключить GPS в меню `Settings > DiLink > General > Apps > Privacy > Location Access = OFF`
- с использованием утилиты [App Manager](/apk/AppManager_443.apk) принудительно остановить и очистить данные следующих приложений *Dynamic system updates, System updates, Otaserver, Update*, после чего перезагрузить ГУ и запросить OTA
- [смена ДНС](/docs/head-unit/adb) на китайский (возможно дополнительно с отключением GPS) и инициация запроса OTA
- перезапуск приложения *otaupdate* с помощью [ADB](/docs/head-unit/adb):

```shell
adb shell pm disable-user --user 0 com.byd.otaupdate
adb shell pm enable com.byd.otaupdate
```

Если включен режим [ADB](/docs/head-unit/adb), то в логах в момент запроса OTA можно наблюдать следующие статусы (фильтр по `OTA_GCY_UPGRADE_Http*`):

```
104 = vehicle up to date
111 = unupgradable version
```
