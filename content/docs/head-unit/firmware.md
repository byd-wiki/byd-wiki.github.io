## Прошивка блока мультимедиа

{{< callout type="warning" >}}
  Прошить на машину для китайского рынка прошивку от машины для глобального рынка, и наоборот - нельзя!
{{< /callout >}}

Для прошивки необходимо:

- подготовить флешку со свободным местом более 16 Gb, форматированную в NTFS либо exFAT
- скачать файл прошивки (например, в канале [BYD Apps & OTA](https://t.me/just_byd)) в соответствии с версией своего ГУ
- переименовать файл в `UpdateFull.zip`
- на флешке создать папку `BYDUpdatePackage`, внутри нее - `msm8953_64` и положить туда файл `UpdateFull.zip`, таким образом, полный путь размещения файла на флешке выглядит следующим образом:
```
BYDUpdatePackage/msm8953_64/UpdateFull.zip
```
- вставить флешку в USB-порт для передачи данных, сразу должно выскочить окошко с предложением провести обновление
- подождать 15-25 минут

При повышении версии прошивки, все файлы и настройки сохраняются. При понижении версии прошивки - производится сброс к заводским настройкам с удалением всех пользовательских программ и файлов (будет показано соответствующее предупреждение).


## Обход QR-кода

Необходимо предварительно установить программу-обходчик [qrcodebypass-1.0.13.apk](/apk/qrcodebypass-1.0.13.apk), запустить и активировать режим пропуска QR-кода.

Если обходчик был установлен до прошивки `2505`, то режим пропуска кода будет работать после удаления обходчика, перезагрузки ГУ и даже после сброса к заводским настройкам.

Обходчик не будет работать в следующих случаях:
- если автомобиль выпущен с завода с прошивкой 2505 и выше, например Sea Lion 06
- если автомобиль получил прошивку 2505 по OTA и ранее обходчик не использовался (в этом случае можно поставить прошивку меньшей версии, установить обходчик и после поставить прошивку нужной версии)

Методы прошивки при невозможности обхода QR-кода:
- ждать получения новой прошивки по OTA
- воспользоваться услугой по сканированию QR-кода (платно, предоставляют те же лица, которые помогает включить режим [ADB](/docs/head-unit/adb)) 
- [не проверено] прошиться через [fastboot](/docs/head-unit/fastboot)


## Частые ошибки

**Не стартует обновление прошивки** 

Система не видит файл прошивки:
- ошибка в наименовании папок
- ошибка в наименовании файла самой прошивки
  - проверьте свойства файла, после переименования бывает, что файл называется *UpdateFull.zip.zip*
  - проверьте содержимое файла, иногда при скачивании файл дополнительно упаковывается в архив. Внутри архива с прошивкой должны находится папки *META-INF* и *anc*, а также файлы *config, dspres*, mcu_*, metadata, update.zip*


**Просит ввести Verification code**

Воспользуйтесь генератором кода https://bydota.crazyurus.com/code


**Показывает QR-код**

Используйте [обходчик QR-кода](/docs/head-unit/firmware/#%d0%be%d0%b1%d1%85%d0%be%d0%b4-qr-%d0%ba%d0%be%d0%b4%d0%b0)


**Ошибка на этапе проверки прошивки** 

Прошивка скачалась с ошибками, либо не подходит под модель авто - проверьте соответствие версии прошивки с версией своего ГУ, перекачайте прошивку
