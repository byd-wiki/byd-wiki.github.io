## Русификация 

В машинах для китайского рынка доступны 2 языка: китайский и английский.

Полная русификация возможна путем заливки модифицированной прошивки в ГУ. Прошивки в свободном доступе отсутствуют. Контакты продавцов можно поискать в канале [BYD Apps & OTA](https://t.me/byd_ota).

Также в продаже имеются и другие языки, например, украинский, арабский.

Минусы использования модифицированной прошивки:
- нет возможности обновления без потери русификации
- русификация слетает при сбросе к заводским настройкам


## Частичная русификация

Для установки русской клавиатуры можно поставить приложение [Gboard](/apk/Google+Gboard+16.4.3.827411866-release-arm64-v8a.apk). Иногда при повторном включении авто это приложение не активно, нужно проверить в меню `Settings > DiLink > General > Default input method = Gboard`

У некоторых приложений изначально есть русский язык, но нужно поставить русскую локаль в системе с помощью приложения [MoreLocale 2](/apk/morelocale-2.4.5_14245.apk):

- устанавливаем приложение
- выдаем права через [ADB](/docs/head-unit/adb)

```shell
adb shell pm grant jp.co.c_lis.ccl.morelocale android.permission.CHANGE_CONFIGURATION
```

- запускаем приложение и выбираем русский язык
