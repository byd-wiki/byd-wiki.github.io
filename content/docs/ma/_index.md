## Возможности МА

После покупки автомобиля для граждан Китая доступна регистрация авто в официальном приложении, оформляется так называемый **Master account** (MA).

Наличие `MA` открывает владельцу дополнительные возможности:

- смартфон в роли ключа;
- просмотр статистики;
- дистанционое управление: из приложения можно открывать/закрывать замки, опускать/поднимать стекла, включать/выключать климат, смотреть камеры, состояние колес и т.п.;
- передавать ограниченные права (из перечисленных выше) другим лицам, - создавать для них **Family account** (FA).

{{< callout type="info" >}}
  По состоянию на **весна 2026**, вне Китая **MA** работает только у следующих автомобилей:
  - [23-й чипсет](/docs/head-unit/versions/#чипсет-23) с версией прошивки `2505` и новее
  - [34-й чипсет](/docs/head-unit/versions/#чипсет-34) с версией прошивки `2511` и новее
{{< /callout >}}

## Приложение BYD

Официальное приложение (только китайский язык) можно загрузить по ссылке: http://i.byd.com.cn/index-mobile.html.

{{< callout type="info" >}}
  Для устройств на базе iOS необходимо предварительно перевести регион Apple Store на *США* либо *Китай*. После установки приложения регион можно вернуть обратно, приложение будет обновляться по мере выхода новых версий.
{{< /callout >}}


Для регистрации в приложении необходим телефонный номер `+86` (Mainland China). Можно сделать [виртуальный телефонный номер](https://www.google.com/search?q=eSender+%D0%BF%D0%BE%D0%BB%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B5+%D0%BA%D0%B8%D1%82%D0%B0%D0%B9%D1%81%D0%BA%D0%BE%D0%B3%D0%BE+%D0%BD%D0%BE%D0%BC%D0%B5%D1%80%D0%B0+%D1%82%D0%B5%D0%BB%D0%B5%D1%84%D0%BE%D0%BD%D0%B0)

При регистрации в приложении `BYD` номер вводится без `+86`.

{{< callout type="note" >}}
  Энтузиастами выполнен перевод официального приложения (**только для Android**) на английский, арабский и русский языки. Последнюю версию можно найти поиском по `EN-AR-RU` в телеграм-канале [BYD Apps & OTA](https://t.me/byd_ota)
{{< /callout >}}


## Получение MA

В общем случае алгоритм получения `MA` выглядит следующим образом:

- оформляете китайский виртуальный телефонный номер через `WeChat` + `eSender` 
- устанавливаете на телефоне китайскую версию приложения `BYD`
- регистрируетесь в приложении
- получаете MA:
  - обращаетесь к продавцу автомобиля для оформления MA (идеальный вариант, как правило, бесплатно),
  - пытаетесь узнать контакты китайского поставщика автомобиля и самостоятельно связываетесь с ним для передачи MA,
  - обращаетесь к "помогаторам" в сети (стоимость в районе 300 USD)

Подробнее см. в прилагаемых файлах:
- [Transfer_MA_New.CN.pptx](./Transfer_MA_New.CN.pptx)
- [Transfer_MA_corporate.RU.docx](./Transfer_MA_corporate.RU.docx)
- [Transfer_MA_corporate.CN.docx](./Transfer_MA_corporate.CN.docx)

При контакте с китайской стороной не лишним будет дополнительно обозначить свой номер паспорта, фамилию и имя на латинице. Известны случаи, когда при выдаче `MA` фамилию и имя писали слитно, либо с 2-мя пробелами, либо вообще использовали русскоязычное написание.


Нормально завершенный созданный `MA` выглядит так: вы вошли в приложение под своим китайским номером и смс в eSender, видите там свой авто; также китайцы вам передали 6-значный пин-код для функций управления.

Полноценное использование MA возможно после организации доступа автомобиля в интернет через [SIM-карту](/docs/internet).


## Минусы МА

Официальный китайский `МА` работает на впаянном в [головное устройство](/docs/head-unit) SIM-чипе с китайским телефонным номером и предоплаченным трафиком, предоставляется в Китае бесплатно при покупке автомобиля и без какой-либо ежемесячной оплаты (если не выходить за рамки бесплатного трафика). Пользуясь официальным `МА`, мы, по сути, *представляемся* для системы этим китайским номером (см. [R-SIM](docs/internet/rsim)). Отсюда следует, что никто не может гарантировать работу официального `МА` за пределами Китая. Производитель в любой момент внедрить какие-либо технические либо программные решения, которые сделают невозможной работу `МА` и сообществу придется искать новые пути обхода этих *ограничений*. И такие примеры были.

Другие минусы:

- Так как решение предназначено для внутреннего рынка Китая, все сервисы (WeChat, eSender, официальное приложение BYD, техподдержка BYD, приложение для диагностики в автомобиле) в основном работают на китайском языке. Да, существуют отдельные локализации, но все равно, вы так или иначе столкнетесь с необходимостью использования переводчика с китайского
- Необходимость покупки (и последующего продления) китайского виртуального телефонного номера (eSender)
- Необходимость впайки [SIM-карты](docs/internet)
- Для работы `МА` и интернета в головном устройстве с одной SIM-карты, ваш мобильный оператор должен поддерживать одновременную работу двух [APN](docs/internet/apn)
- Ежемесячные расходы на SIM-карту (оплата тарифа)
- Оплата услуги за оформление `МА` (если `МА` не был бесплатно предоставлен при покупке авто)


## Проблемы

Весной 2026 г. после технических работ на серверах BYD часть автовладельцев столкнулась с потерей связи с автомобилем через `МА`. Оказалось, что некоторые автомобили перевели на другой сервер, на котором стоит фильтр по IP-адресу. Подключиться можно только с китайским либо гонконгским IP. Рабочие варианты для решения проблемы:

- Использование китайской SIM-карты в роуминге (дорого!)
- Покупка eSIM адаптера (совместимого с easyEUICC) и запись на него Гонконгской (3HK) eSIM (можно выбрать тариф на сайте https://mobimatter.com).

Теоретические варианты (не проверены сообществом, нет подробной инструкции в открытом доступе):
- ручное изменение маршрутов (требуется root-доступ)
- договориться с мобильным оператором на private APN, с которого направлять трафик на собственный сервер в Китае либо Гонконге


## Альтернативы МА

Существуют сторонние программно-аппаратные решения, основанные на установке в автомобиль специального блока, содержащего в себе клон ключа от авто:

- [BYD EV Pro](/docs/software)
- [BYD Help](https://t.me/BYDhelp)

Также в качестве альтернативы можно рассматривать ограниченное использование `МА` без впайки SIM-карты - только для управления со смартфона по BlueTooth вблизи авто. Для этого необходимо зарегистрировать `МА` и связать автомобить с серверами BYD в то время, пока он еще в Китае. Либо, если вы находитесь недалеко от границы с Китаем, съездить к границе, чтобы автомобиль словил китайскую мобильную сеть и зарегистрировался на серверах BYD. Либо использовать китайскую SIM-карту в роуминге.
