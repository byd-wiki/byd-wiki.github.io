title: Организация связи через WiFi
type: docs
weight: 10
prev: docs/ma/

Стандартно связь автомобиля с облаком BYD возможна через SIM-карту. Исследователи обнаружили возможность изменения настроек системного процесса **cloudmanager**, позволяющую для связи с облаком использовать WiFi. Настройка выполняется в приложении [OpenWIFI](/apk/openwifi-4.18.apk).
